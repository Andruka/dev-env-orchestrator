# Журнал изменений

Версии идут по схеме «мажорная.минорная.патч». Самое новое — сверху. Панель показывает этот список в «Настройки → Обслуживание → Обновления».

## 1.1.1 — 2026-11-11
- Исправлено: «Развернуть с нуля» и «Поднять (dup)» падали с ошибкой `Pool overlaps with other one on this address space`, если в другом репозитории (server, server-copy, …) раньше поднималась ветка. Во всех таких репозиториях в compose-файле одна и та же подсеть, а «Остановить» удаляло контейнеры, но оставляло сеть. Теперь перед запуском и после остановки панель удаляет пустые сети других compose-проектов, занимающие нужную подсеть; если её держит проект с работающими контейнерами, пишет, какой именно остановить.
- Подсказка «Подсеть docker уже занята» с кнопкой «Удалить пустые сети» (на случай запуска не из панели).
- Новый тип шага `freeSubnets` для своих кнопок: освобождает подсети из указанного compose-файла.
- Стенды 5005 и 5006 получили конфиг фронтенда.

## 1.1.0 — 2026-10-31
- Swagger: группа «Swagger» с кнопками «Собрать и запустить», «Запустить», «Открыть Swagger UI», «Открыть mock», «Редактор», «Проверить спецификацию», «Остановить». Папка репозитория и порты настраиваются в «Пути и порты».
- Предупреждение о несовпадении стенда бэкенда и фронтенда теперь с исправлением: переключить стенд, показать переменные для IDE или остановить процесс на порту.
- Проверка соединения со стендом («Проверить соединение»): сервер отвечает, логин принят, данные пользователя получены.
- Диагностика при запуске: панель сама проверяет окружение и сообщает о проблемах.
- Раздел «Обслуживание»: проверка окружения, место на диске (снимки, дампы, docker), журнал действий, обновления и версия.
- Освобождение места: старые снимки БД, дампы, образы и кэш сборки docker, резервные копии файлов окружения.
- Обновление панели из git одной кнопкой (fast-forward) с перезапуском; проверка новых версий в фоне.
- Журнал действий: что и когда делалось (задачи, стенды, снимки, освобождение портов).
- Снимки БД подписываются стендом и веткой; при восстановлении снимка с другого стенда панель предупреждает.
- Понятные ошибки: типичные сбои (занятый порт, docker не запущен, нет места, git не пускает, неверный логин) показываются с причиной и готовым действием.
- Поиск по проектам и подсветка текущей ветки.
- Мастер первого запуска: корневая папка, проверка окружения, вход, стенды и Swagger за пять шагов.
- Экспорт и импорт профиля для коллег: кнопки, группы, стенды и оформление без путей, паролей и файлов стендов.

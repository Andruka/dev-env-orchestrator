# Dev Panel

Локальная веб-панель для рутины разработки CalPlan: ветки, docker compose, дампы и снимки БД, стенды, фронтенд и вход в него, Swagger.
Node 22+, внешних зависимостей нет, слушает только `127.0.0.1`. Версия и история изменений: [CHANGELOG.md](CHANGELOG.md).

## Быстрый старт

```sh
./dev-panel-<версия>.run     # установщик: проверит окружение, задаст пару вопросов, добавит значок в меню
dev-panel                    # запустить и открыть окно
```

При первом запуске откроется **мастер настройки** (папка с репозиториями → окружение → вход → стенды → Swagger); его можно пройти позже с приветственной карточки.

Из каталога с исходниками: `ln -s "$PWD/bin/dev-panel" ~/.local/bin/dev-panel && dev-panel setup`.

Перед установкой нужны (панель их не ставит): **Node.js 22+, git, docker с compose, zstd, Brave/Chrome/Chromium** и
доступ к docker без sudo (`sudo usermod -aG docker $USER`). Проверка: `dev-panel doctor`.

## Что умеет

**Ежедневная работа**
- **Репозитории и ветки:** группы бэкенд / фронтенд / Swagger и свои; смена ветки, подтянуть, stash; поиск проектов (`/`), подсветка текущей ветки.
- **Docker compose и БД:** «Развернуть с нуля», накат дампа без pgAdmin, **снимки БД** с пометкой стенда и ветки и предупреждением при откате на другой стенд.
- **Стенды:** переключение `.env` бэкенда и `config.js` фронтенда (файлы могут лежать вне репозитория), переменные стенда для IDE, логин и пароль; переключатель в верхней полосе, проверка соединения; предупреждение, если бэкенд и фронтенд на разных стендах, с готовым исправлением.
- **Вход во фронтенд** одной кнопкой и автопродление токена.
- **Swagger:** сборка, запуск UI, mock и редактора, открытие локального Swagger в браузере; путь к репозиторию у каждого свой и задаётся в настройках.

**Удобство**
- **60 тем** оформления (в том числе мягкие для долгой работы, высокий контраст, фановые), поиск, избранное, автопара светлая/тёмная; плотность, палитра команд `Ctrl+K`, горячие клавиши.
- **Лог:** фильтр строк, перенос, сохранение в файл; история запусков переживает перезапуск; уведомления и звук по завершении.
- **Подсказки при ошибках:** занятый порт, docker, место на диске, доступ по ssh, 401/403 и другие — с кнопкой исправления.

**Обслуживание** («Настройки → Обслуживание»)
- проверка окружения при запуске и по кнопке;
- очистка диска (снимки, дампы, docker) только по подтверждению;
- журнал действий без паролей;
- обновление панели и «Что нового»;
- экспорт и импорт профиля для коллег — без паролей и личных путей.

**Безопасность**
- **Только безопасный git:** fetch, checkout, `pull --ff-only`, stash — без commit/push/merge/reset (в том числе в ваших кнопках).
- Пароли только в `~/.config/dev-panel/secrets.json` (права 600), не попадают в конфиг, экспорт и git.
- Запросы принимаются только с localhost и своего Origin.

## Команды

```sh
dev-panel [web|stop|restart|status|logs|fg|setup|doctor|autostart on|off|desktop on|off|version]
npm test                     # тесты (включая UI-проверку в headless-браузере)
npm run themes               # перегенерировать темы и проверить контраст
npm run build:installer      # собрать dist/dev-panel-<версия>.run
scripts/sandbox.sh [порт]    # отдельный экземпляр со своим HOME для проверок
scripts/try-install.sh       # пробная установка с нуля в отдельной «домашней папке» (docker не изолирован)
```

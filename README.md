# Dev Panel

Локальная веб-панель для рутины разработки CalPlan: ветки, docker compose, дампы и снимки БД, фронтенд и вход в него.
Node 22+, внешних зависимостей нет, слушает только `127.0.0.1`.

## Быстрый старт

```sh
./dev-panel-<версия>.run     # установщик: проверит окружение, задаст пару вопросов, добавит значок в меню
dev-panel                    # запустить и открыть окно
```

Из каталога с исходниками: `ln -s "$PWD/bin/dev-panel" ~/.local/bin/dev-panel && dev-panel setup`.

Перед установкой нужны (панель их не ставит): **Node.js 22+, git, docker с compose, zstd, Brave/Chrome/Chromium** и
доступ к docker без sudo (`sudo usermod -aG docker $USER`). Проверка: `dev-panel doctor`.

## Что умеет

- **Репозитории** выбираются через проводник в «Настройки → Репозитории»; можно создавать свои группы.
- **Кнопки** можно добавлять, менять, скрывать и удалять; системные восстанавливаются к исходным (↺).
- **15 тем** оформления (7 из них мягкие, для долгой работы) + «как в системе», плотность, горячие клавиши, палитра команд `Ctrl+K`.
- **Снимки БД**, быстрый «Развернуть с нуля», накат дампа без pgAdmin.
- **Стенды:** переключение `.env` бэкенда и `config.js` фронтенда между готовыми вариантами (по одному файлу или стендом целиком), переменные стенда для запуска из IDE, вход следует за выбранным стендом.
- **Вход во фронтенд** и автопродление токена.
- **Только безопасный git:** fetch, checkout, `pull --ff-only`, stash — без commit/push/merge/reset (в том числе в ваших кнопках).
- **Проверка окружения** (`dev-panel doctor` или «Настройки → Обслуживание») подсказывает, чего не хватает.
